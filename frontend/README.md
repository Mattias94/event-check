# Frontend (Next.js)

Scaffolded minimal Next.js App Router app with Tailwind CSS setup.

To run locally:

```bash
cd frontend
npm install
npm run dev
```

Created pages:
- `app/(auth)/register/page.tsx`

Components:
- `components/AuthLayout.tsx`
- `components/AuthForm.tsx`
- `components/ui/Input.tsx`
- `components/ui/Button.tsx`
